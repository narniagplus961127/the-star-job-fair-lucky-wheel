JSON configuration example

Use this structure for every custom game. Add one object to the prizes array for each unique prize. 

{
  "prizes": [
    {
      "id": "grand-prize",
      "name": {
        "en": "Wireless Headphones",
        "ms": "Fon Kepala Tanpa Wayar"
      },
      "quantity": 1,
      "probability": 10,
      "tier": "grand",
      "graphic": "headphones.jpg",
      "color": "#d71920"
    },
    {
      "id": "gift-pack",
      "name": {
        "en": "Job Fair Gift Pack",
        "ms": "Pek Hadiah Pameran Kerjaya"
      },
      "quantity": 20,
      "probability": 90,
      "tier": "consolation",
      "graphic": "gift-pack.jpg",
      "color": "#2878c8"
    }
  ]
}

JSON field rules

id
A unique, non-empty text ID for the prize.
name.en / name.ms
Prize names in both supported languages.
quantity
A whole number of zero or greater.
probability
A positive number. All initial prize probabilities must total 100.
tier
grand, second, third or consolation.
graphic
The exact image filename, including its extension.
color
A six-digit hexadecimal colour.
or

How to upload a custom game

  1. Prepare one JSON file using the JSON guide tab and include at least two prizes. The file must be no larger than 1 MB.
  2. Prepare every image named in graphic. Use PNG, JPEG or WebP files up to 2 MB each.
  3. Choose the JSON file, then select all referenced prize images together.
  4. Select Load custom game. The files are validated before replacing the active game.

JSON and images are selected separately. Every image filename must exactly match its graphic value, including uppercase letters and the file extension.
